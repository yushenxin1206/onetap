# 轻启 / OneTap — 结构草稿

## 交付物
- outputs/index.html 设计稿入口（含可交互原型 + 关键页面 + 设计规范）
- outputs/styles.css / prototype.js
- outputs/tech-spec.html 技术方案

## 关键页面
1. 快捷操作首页：Hero 快捷卡（QQ 音乐每日推荐）+ 2×2 快捷格子 + 浮动 Dock
2. 操作编排：选 App → 选动作 → 触发方式 → 命名 → 可行性提示
3. App 选择器：搜索 + 已安装列表 + 能力标签（支持深链 / 仅能打开 / 需快捷指令）
4. 执行中：底部 Sheet，分步状态、可取消
5. 结果 · 成功（诚实文案：已打开，不谎称已播放）
6. 结果 · 失败 / 降级（未安装、路由失效 → 装 App / 复制链接 / 用网页）
7. 锁屏小组件 + 控制中心入口

## 设计 token
- 背景 #F2F0EA / 卡面 #FFFFFF / 墨色 #141413 / 强调 #FF5A1F
- 圆角 28 / 22 / 16，行高紧凑，字号 34 / 22 / 15 / 12
- 动效：Sheet 320ms cubic-bezier(.32,.72,0,1)，按压 120ms

## 技术结论（详见 tech-spec.html）
- 第三方 App 无法在 iOS 上"遥控"另一个 App 的内部行为，没有跨应用 UI 自动化。
- 能做到：深链打开到具体页面（Universal Link 优先、URL Scheme 兜底）、通过快捷指令桥执行用户自建动作、把入口铺到小组件/控制中心/Siri。
- "一键播放 QQ 音乐今日推荐"真实上限：一次点击 → 落在每日推荐页 → 用户点播放（2 步）；真·一键自动播放只能走"App 内播放"（开放平台 SDK）。
- 设计必须诚实：结果文案是"已打开每日推荐"，不是"播放成功"。
